# Exports da solution do Copilot Studio

Esta pasta versiona os exports da *solution* do Copilot Studio (arquivo `.zip`
exportado do ambiente, ou seu formato descompactado). O export é o "backup"
da configuração do agente: permite restaurar o ambiente, migrar entre
dev/homologação/produção e rastrear a evolução da configuração.

Convenção de nome sugerida: `solucao-portfolio-vX.Y.Z.zip`, acompanhando o
versionamento SemVer do projeto.

> Vazia até o primeiro export (sprints técnicas).
